# Lookback Return Momentum V1 백테스트 리포트

Lookback Return Momentum은 최근 N개 완료봉의 종가 수익률이 충분히 크면 그 방향의 흐름이 다음 몇 개 봉에도 이어질 수 있다고 보는 전략입니다. 가격이 기준 이상 올랐으면 Long, 기준 이하로 내렸으면 Short로 진입하고, 손절·익절·시간 청산으로 포지션을 닫습니다. 이번 리포트는 이 아이디어가 1m과 15m에서 거래비용과 손익비를 넘는지 확인한 결과입니다.

## 2. 가설

이번 백테스트는 close-to-close 모멘텀 신호가 짧은 보유 구간에서도 같은 방향으로 이어지는지 확인합니다.

- 최근 N개 완료봉 수익률이 기준 이상이면 이후 holding_bars 동안 같은 상승 방향 수익률을 보일 것이다.
- 최근 N개 완료봉 수익률이 기준 이하이면 이후 holding_bars 동안 같은 하락 방향 수익률을 보일 것이다.

## 3. 전략에 포함된 가정과 이론적 배경

이 전략은 가격이 모든 정보를 즉시 반영하지 않을 수 있다는 가정에서 출발합니다. 단기적으로는 주문 흐름, 유동성 공백, 추세 추종 참여자, 손절성 물량이 한 방향의 움직임을 몇 개 봉 더 이어가게 만들 수 있습니다. 이때 최근 N개 봉의 수익률은 복잡한 주문장 정보를 직접 보지 않고도 단기 수급 압력을 요약하는 대체 지표가 됩니다.

전략이 기대하는 경제적 구조는 다음과 같습니다.

- 최근 상승이 강하면 매수 우위가 아직 해소되지 않았을 가능성이 있고, 가격이 익절선까지 이어질 수 있습니다.
- 최근 하락이 강하면 매도 우위가 아직 남아 있을 가능성이 있고, Short 포지션의 목표가에 도달할 수 있습니다.
- 손절 1.0R과 익절 1.5R의 구조에서는 방향이 매번 맞을 필요는 없지만, 승률과 평균 이익이 비용을 포함한 손실을 넘어야 합니다.
- 신호가 빠를수록 초반 흐름을 잡을 가능성은 커지지만, 거래 회전율도 올라가 수수료·스프레드·슬리피지 부담이 커집니다.

성공하는 경우에는 최근 수익률 임계값이 실제 후속 주문 흐름을 잡고, 목표가 도달 거래가 충분히 누적됩니다. 실패하는 경우에는 임계값을 넘은 움직임이 이미 소진된 가격 이동이거나, 남은 변동 폭이 비용과 손절 구조를 넘지 못합니다. 따라서 이 전략의 성과는 모멘텀 신호 자체보다 비용 차감 후 기대값으로 판단해야 합니다.

```text
E[R] = P(win) x AvgWin - P(loss) x AvgLoss - Cost
```

이번 결과의 Expectancy는 1m -0.1971 USDT, 15m -0.2693 USDT였습니다. 두 값 모두 음수라서, 저장된 구간에서는 신호가 비용과 손익비를 넘는 구조로 이어지지 않았습니다.

## 4. 전략 규칙

### 진입 조건

| 구분 | 1m 설정 | 15m 설정 |
|---|---:|---:|
| lookback_bars | 20 | 8 |
| entry_threshold | 0.1% | 0.2% |
| holding_bars | 5 | 4 |
| risk_distance_pct | 0.2% | 0.2% |
| stop_loss_r | 1.0R | 1.0R |
| take_profit_r | 1.5R | 1.5R |

- 포지션이 없을 때만 새로 진입합니다.
- `momentum_return >= entry_threshold`이면 Long으로 진입합니다.
- `momentum_return <= -entry_threshold`이면 Short로 진입합니다.
- 반대 신호가 나오더라도 포지션을 뒤집지 않습니다.

### 청산 조건

| 항목 | 내용 |
|---|---|
| 손절 기준 | 진입가에서 0.2%를 1R로 두고 1.0R 손절 |
| 익절 기준 | 1.5R 익절 |
| 시간 제한 | 1m은 5개 봉, 15m은 4개 봉 |
| 동일 캔들 처리 | 손절과 익절이 모두 가능한 경우 손절 우선 |
| 체결 가정 | 완료봉 종가 기준 진입, 이후 OHLCV 고가·저가로 손절/익절 확인 |

## 8. 해석

이번 결과는 Lookback Return Momentum V1이 저장된 구간에서 비용과 손익비를 넘는 구조를 만들지 못했음을 보여줍니다. 비용 차감 전 손익이 1m -0.7767 USDT, 15m -0.0390 USDT였기 때문에, 문제를 비용 모델 하나로만 설명할 수 없습니다. 신호가 포착한 최근 수익률이 다음 보유 구간의 충분한 후속 움직임으로 이어지지 않았고, 그 위에 거래비용이 더해졌습니다.

관찰된 원인은 다음과 같습니다.

- 1m은 빠르게 반응했지만 거래가 1,285회로 늘었고, 시간 청산 1,178회가 누적됐습니다. 신호 속도는 높았지만 거래당 기대 움직임이 작아 비용을 흡수하지 못했습니다.
- 15m은 거래 수가 169회로 줄었지만 손절 72회, 익절 43회, 시간 청산 54회였습니다. 회전율을 낮추는 것만으로는 신호 품질과 손익비가 개선되지 않았습니다.
- 1.5R 익절 구조는 비용 이전의 설계상 이점이 있지만, 실제로는 목표가 도달 빈도와 시간 청산 결과가 함께 기대값을 결정합니다. 이번 저장 결과에서는 그 조합이 양수 기대값으로 연결되지 않았습니다.
- Long과 Short 모두 비용 반영 후 순손익이 음수였습니다. 특정 방향 하나만의 문제가 아니라, 현재 close-to-close 임계값이 해당 구간의 후속 흐름을 충분히 구분하지 못한 결과로 해석하는 편이 자연스럽습니다.

보완점은 다음과 같습니다.

- 5m 비교를 별도 산출물에서 확인해야 합니다. 1m은 너무 자주 거래했고 15m은 느렸기 때문에, 중간 시간축이 회전율과 비용의 균형을 바꿀 수 있는지 확인할 필요가 있습니다.
- entry_threshold와 비용 차감 후 순손익비 조건을 함께 점검해야 합니다. 비용 차감 전 손익이 양수가 아니었으므로, 더 강한 신호만 남겼을 때 거래 수는 줄고 평균 후속 움직임은 커지는지 봐야 합니다.
- holding_bars를 청산 구성과 함께 다시 봐야 합니다. 1m의 시간 청산 비중이 매우 높았기 때문에, 보유 시간이 너무 짧아 익절까지 가지 못한 것인지, 반대로 신호 자체가 약해 시간을 늘려도 손실이 커지는지 분리해야 합니다.
- 거래량이나 변동성 조건은 별도 전략 변형으로 검토해야 합니다. 현재 규칙은 가격 수익률만 보므로, 수급이 약한 움직임과 실제 추세 전개를 구분하지 못할 수 있습니다.
